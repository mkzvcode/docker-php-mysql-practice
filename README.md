# Практика: создание образа PHP + MySQL

Проект по презентации «Создание образа», включая дополнительное задание с phpMyAdmin.

## Запуск

Откройте терминал в этой папке и выполните:

```sh
docker compose up --build -d
docker compose ps
```

Сайт: http://localhost:8080

phpMyAdmin: http://localhost:8081

Для входа в phpMyAdmin: пользователь `appuser`, пароль `apppass`.
База `appdb`, таблица `users`: МАКСОН, ТИМУРКА, ЕГОРКАААА.
Учебные пароли предназначены только для локальной практики.

## Что показать преподавателю

1. Dockerfile: базовый PHP 8.2 + Apache, установка PDO MySQL, копирование кода.
2. docker-compose.yml: сервисы web, db, phpmyadmin, общая сеть и том db_data.
3. `docker compose ps`: три запущенных контейнера, база healthy.
4. http://localhost:8080: успешное подключение и пользователи из БД.
5. http://localhost:8081: таблица appdb.users в phpMyAdmin.

## Остановка

```sh
docker compose stop
```

Повторный запуск: `docker compose up -d`.
Удаление контейнеров без удаления данных: `docker compose down`.
Данные сохраняются в томе; init.sql выполняется только при первом создании БД.
После изменения PHP достаточно обновить страницу, пересборка не нужна.

Отличия от примера: устаревшая строка version убрана; добавлена проверка готовности
MySQL перед запуском сайта; порты доступны только с этого компьютера; имена
контейнеров формируются Compose для отдельного проекта.
